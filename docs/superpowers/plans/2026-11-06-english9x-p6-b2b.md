# P6 — B2B vận hành: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Trung tâm và doanh nghiệp quản lý thành viên, lớp/nhóm, giao bài, lịch học, điểm danh, báo cáo; trung tâm cấu hình bên chấm, soạn nội dung riêng và đề xuất khoá lên kho chung.

**Architecture:** `classroom` (lớp, giao bài, buổi học, điểm danh), mở rộng `org` (thành viên, mã tham gia), `analytics` (báo cáo), `catalog`/`course` (cấu hình chấm trung tâm, kho chung). Mọi bảng có `owner_org_id NOT NULL` + RLS theo L1d. Doanh nghiệp: UI gọi "Nhóm", ẩn tính năng giáo viên/nội dung.

**Tech Stack:** Spring Boot, Apache POI (xuất/nhập Excel), JPA; React.

**Spec:** §12, §13 (nhắc lịch, bài giao), §7.1 (kho chung). Global Constraints + Review Focus #1: overview.
